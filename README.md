## 能做的风格（样品）

1. **汉服山顶**：白衣白发汉服，群山之巅，腰间拔剑、云层随剑慢慢劈开，近景切远景。
2. **雨天商业广场**：可爱风，蓝色针织 + 粉色裙子，雨天逛街，突然走入镜头对镜头微笑。
3. **雪中漫步 / 西藏骑马**：风景 + 人物，远近景切换。
4. **房间日常**：米色针织上衣 + 牛仔短裤，男友视角，居家氛围。
5. **时尚街拍**：美式裹胸上衣 + 短裤，街头、商场场景。
6. **浴室前准备**：刚开始准备洗澡、脱外衣扔进洗衣框，镜头拉远，真实感优先，无裸露。

样品视频在闲鱼商品图 / 视频里直接看，仓库里只留文字说明，不放客户隐私素材。

## 下单要给的信息

复制这段发给卖家就行：

```
1. 要做哪种：写真 / 跳舞视频 / 短剧
2. 人物参考图：发一张照片（没有就用默认女主）
3. 衣服：颜色 + 款式，例如蓝色针织 + 粉色裙子
4. 场景：在哪里，例如雨天商业广场、雪山、房间
5. 动作 / 台词：例如走入镜头微笑 / 说一句话
6. 时长：10 秒 / 15 秒
7. 要不要加急：是 / 否
```

## 交付流程

1. 闲鱼拍下 → 发上面 7 条信息
2. 确认能做、确认价格 → 开始做
3. 24 小时内发预览（带水印小图 / 低清预览）
4. 确认没问题 → 发原片下载链接
5. 免费改 1 次，确认收货

## 不接的单

- 裸露、色情、未成年人相关
- 冒充真实公众人物、冒充他人身份
- 违法、诈骗、侵权素材（用别人的照片冒充本人）
- 要求“和真人实拍一模一样、一点 AI 痕迹都没有”——做不到，会提前说
